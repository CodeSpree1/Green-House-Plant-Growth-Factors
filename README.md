# Green-House-Plant-Growth-Factors
This project involves the comprehensive analysis and visualization of plant growth data collected from a controlled greenhouse environment. The dataset, Greenhouse Plant Growth Metrics, contains various physiological and morphological measurements of plants categorized by different experimental groups, identified by the variables Class and Random.

# Objectives:
	•	Data Cleaning and Preparation:
The raw dataset is first cleaned by removing any missing values, ensuring the analysis is performed on complete and valid data.
	•	Data Transformation:
Categorical columns Class and Random are converted to numerical codes to facilitate statistical analysis and plotting.
	•	Exploratory Data Analysis (EDA):
Key exploratory steps include inspecting the dataset’s structure, identifying unique groups, and calculating correlations among important plant growth metrics to understand their interrelationships.
	•	Statistical Analysis:
The project computes mean values of various plant growth features for every combination of Class and Random groups. This allows for comparative analysis across different experimental conditions.
	•	Data Visualization:
Using Matplotlib, the project generates a grid of bar charts showing mean values of multiple plant growth parameters. Each subplot represents a unique combination of Class and Random categories, facilitating easy comparison across groups.

⸻

# Key Features and Metrics Analyzed:
	•	ACHP, PHR, AWWGV, ALAP, ANPL, ARD, ADWR, PDMVG, ARL, AWWR, ADWV, PDMRG
(Physiological and morphological parameters reflecting plant health, water use, leaf area, and growth rates)
	•	Class and Random
(Categorical variables representing experimental groups or treatments)
